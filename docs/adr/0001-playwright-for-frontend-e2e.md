# Использовать Playwright для браузерных тестов фронтенда

Для главной страницы требуется проверять её открытие в браузере и реальные
переходы по ссылкам на `/book`. Выбран Playwright с Chromium: он проверяет
поведение пользователя, включая клик и смену URL, а не только разметку
компонента.

## Considered Options

- **Playwright** — запускает сценарии в настоящем браузере и подтверждает
  открытие страницы и переходы. Требует установки браузера и дополнительного
  шага в CI.
- **Vitest с Testing Library** — проще запускать, но jsdom не выполняет
  браузерную навигацию обычных ссылок. Такие тесты проверяли бы `href`, а не
  фактический переход, поэтому не закрывают требование.
- **Только линтеры и TypeScript** — не проверяют поведение страницы.

## Consequences

- Chromium устанавливается при локальной настройке проекта, а в GitHub Actions
  — вместе с системными зависимостями Ubuntu.
- Тесты запускаются через `mise run test:frontend` и входят в общий
  `mise run check`.
- Используются только Chromium и desktop viewport; отдельная инфраструктура
  компонентных тестов не добавляется.
- Пока страница `/book` не реализована, тесты проверяют только переход на её
  URL, без предположений о её содержимом.
