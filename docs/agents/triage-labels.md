# Метки triage

Навыки используют две канонические категории и пять состояний triage. Этот файл
связывает роли со строками меток в issue tracker репозитория.

## Категории

| Метка в mattpocock/skills | Метка в tracker | Значение |
| ------------------------- | --------------- | -------- |
| `bug` | `bug` | Некорректное поведение существующей функциональности |
| `enhancement` | `enhancement` | Новая возможность или улучшение |

## Состояния

| Метка в mattpocock/skills | Метка в tracker | Значение |
| ------------------------- | --------------- | -------- |
| `needs-triage` | `needs-triage` | Ответственный должен оценить задачу |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Полностью специфицирована, готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Требует реализации человеком |
| `wontfix` | `wontfix` | Не будет реализована |

Когда навык упоминает роль (например, «применить метку готовности для
AFK-агента»), используйте соответствующую строку из таблицы.

Автоматический первичный триаж новых issues может присваивать только категорию
и состояния `needs-triage` или `needs-info`. Он пропускает issue с любой уже
установленной меткой состояния, сохраняет одну существующую категорию и не
разрешает конфликты нескольких категорий. Готовые состояния и `wontfix`
присваивает maintainer через обычный процесс triage.

Измените колонку «Метка в tracker», если используется другой словарь.
